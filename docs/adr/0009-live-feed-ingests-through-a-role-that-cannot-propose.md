# The live feed books raw rows through a role that can do nothing else

Bank lines and invoices arrive from a feed in the agent gateway, which holds its own identity with a feed role whose only powers are the two ingest reducers: it cannot propose, rule or post, so a broken or hostile feed can add rows for the Bookkeeper to explain but can never change a balance. The module refuses ingestion unless the CFO has switched the feed on (a setting changed through a reducer, so the switch is audited) and only into an open month whose previous month the CFO locked (a lock that came with the seed data does not count) and whose own close has not started, so feed rows never land in a month that is being closed or is already closed. Every row carries an external id recorded with it, so a replayed row is skipped rather than booked twice, and one bad row refuses its whole batch because a reducer rolls back atomically and there is no partial ingest to reconcile. Resetting the demo also turns the feed off.
