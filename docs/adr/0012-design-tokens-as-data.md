# Design decisions are data in `packages/design-tokens`, and checks arbitrate

The web app's colours, type scale, radii and agent-role colours used to live as hand-kept CSS variables in `apps/web/src/app.css`, with the rules about them (one accent per view, uniform neutral borders, sentence-case labels) living in people's heads and chat logs. Agents building screens drifted: about fifty colour classes in components named tokens that never existed, so the elements rendered unstyled, and sizes were picked by feel as bracketed pixel values. Now every design decision is a token in `packages/design-tokens/tokens/*.tokens.json`, in the W3C Design Tokens Community Group format, in three tiers: primitives (the palette ramps, which only the semantic tier may read), semantic (what a value is for: `canvas`, `ink`, `accent-soft`, `on-accent-soft`, `pos`, `info`, the type steps, the radii) and the agent-role colours. Terrazzo builds the semantic tier into `css/cafoo-tokens.css`, resolved per mode (light, dark), followed by a Tailwind `@theme` block that maps each token to a utility class and switches off Tailwind's own palette and size names, so a class that is not a token does not exist. Palette and size primitives never reach the CSS; only the font stacks appear, inside the Tailwind theme. Tokens that are easy to misuse carry `usage` and `rules` under `$extensions["com.cafoo"]` (the field names GitHub Primer uses), written as "Never" and "Only" sentences for the agents that read the files directly. Vitest checks turn the rules into failures rather than reminders: the committed CSS must equal a fresh build, every pair in `contrast.json` must meet WCAG in both modes, usage notes must keep their format, and a scan of `apps/web/src` counts raw hex and rgb values, bracketed pixel sizes, Tailwind palette classes and unknown colour classes against a per-file baseline that may only go down. A description informs; a check arbitrates. Component contracts (one neutral file per component describing anatomy, props and allowed combinations, as Nathan Curtis describes) were considered and deferred: they pay off with a second code platform or a design studio, and Cafoo has one web app and no designer yet. Borders are deliberately low-contrast hairlines and are excluded from the contrast pairs; focus rings and text are not. The migration of `app.css` and the components onto the generated file is front-end work tracked by the baseline; until it lands, `app.css` keeps its own variables and the generated file is not yet imported.
